# Hangman Game

## Description
This is a simple text-based Hangman game developed using Python. The player guesses a randomly selected word one letter at a time.

## Features
- Contains 5 predefined words.
- Randomly selects a word.
- Allows the player to guess one letter at a time.
- Maximum of 6 incorrect guesses.
- Displays the progress of the word.
- Prevents repeated guesses.
- Provides console-based input and output.

## Technologies Used
- Python
- Google Colab

## Python Concepts Used
- Random module
- While loop
- If-else statements
- Strings and lists
- For loop
- User input

## How to Run
1. Install Python on your computer.
2. Download `hangman.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the command:

```bash
python hangman.py
```

5. Enter one letter at a time to guess the word.
